## F0 契约决定

| 项目 | 实施决定与实际依据 |
| --- | --- |
| C01 | EventQueryService.Summary 仅含 eventId/eventType/endpointId/status/latestRoundNo/createdAt。列表保留这些字段，尝试次数和最近时间只在详情展示；不逐行请求、不拼投递列表。 |
| C02 | DeliveryHistoryQueryService.Round 未公开 URL/超时/退避快照。详情明确接口未提供，不拿当前配置冒充快照。 |
| C03 | 内部 JSON 数字 ID 仍按数字提交。无损解析后验证安全整数，超出范围拒绝并报告契约错误，不能舍入后使用。完整 long 需前后端协商字符串迁移。 |
| C04 | 审计 actorUserId 为内部数字 ID，objectId 为字符串；只展示内部 ID，不伪造名称、不跳转外部事件。七个 action 按 P10-03 映射。 |
| C05 | 创建事件为202事件摘要；重投为202 TaskSummary；接收端创建201，启停/编辑200，无体POST不能传{}。响应统一边界验证。 |
| C06 | 接收端选择器20条一页，显式上一页/下一页，无虚假搜索；仅说明当前页可选情况，停用项创建时禁用。 |
| C07 | 外部创建专用请求，不进入 mutation cache；秘密只保存在交付弹窗状态，关闭必须确认已保存，卸载/会话结束清空。 |
| C08 | payload用lossless-json保留数值词法，完整UTF-8请求<=262144字节；ID路径encodeURIComponent。后端%编码路径已知会401，保守拦截含路径保留字符的详情操作，提示精确列表可查且不误清会话。 |

默认进入/events；列表page=1,size=20且无默认时间筛选；概览最近7个本地日历日，结束为明日午夜（不包含）。UTC URL保留精确边界，页面注明本地时区。会话策略按后续用户要求调整为标签页sessionStorage缓存，刷新恢复未过期Token，密码不缓存；退出/过期/认证失败清除，仍无refresh或/me接口。仅dev预填用户指定的本地演示账号，生产不预填，不改变后端账户。手动刷新、无轮询，写操作不重发。

## 视觉与工程决定
